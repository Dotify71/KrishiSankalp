## 🚜 About the Project

**AI KrishiSahyogi** is a web-based smart farming assistant that helps farmers make informed decisions about what crops to plant based on their specific farm conditions. By analyzing inputs such as location, soil type, season, water source, farm size, and budget, the system provides personalized crop recommendations, current market analysis, and weather insights to maximize yield and profitability.

## ✨ Features

- **Personalized Crop Suggestions:** Get AI-based recommendations tailored to your specific location, soil type, and season.
- **Market Analysis:** Access relevant market information and potential profits to forecast revenue.
- **Weather Insights:** View relevant weather data to plan farming activities effectively.
- **Intuitive User Interface:** A clean, easy-to-use form to input farm details and instantly receive recommendations across interactive tabs.
- **Responsive Design:** Works seamlessly across desktops, tablets, and mobile devices.

## 🛠️ Technologies Used

- **HTML5:** For the structural foundation of the application.
- **CSS3:** For styling, layout (`style.css`), and responsive design elements.
- **JavaScript (Vanilla):** For form handling, dynamic tab switching, and recommendation logic (`script.js`).
